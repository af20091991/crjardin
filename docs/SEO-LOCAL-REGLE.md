# SEO Local

Le module SEO Local sépare les deux sources réelles utilisées par Pilot Pro :

- Search Console : requêtes contenant les communes de la zone ciblée, avec clics, impressions, CTR et position organique.
- Google Business Profile : clics vers le site, appels, demandes d'itinéraire et impressions Search/Maps issues de l'API officielle.

Une indisponibilité d'une source ne doit pas masquer les données disponibles de l'autre source.

Le module ne présente aucun rang Google Maps calculé ou estimé lorsque cette donnée n'est pas fournie par une source réelle.
